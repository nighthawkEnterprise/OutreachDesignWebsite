# Outreach Design Website

Outreach Design Website is a React-based marketing website for a web design and consulting service concept. It includes a public homepage, service sections, portfolio content, contact flow, and supporting pages for a small agency-style web presence.

## Overview

This project explores how to package a service business online: explaining the offering, showing examples of work, routing visitors to contact or get-started flows, and presenting credibility through service and portfolio sections.

## Product problem

Small businesses and early-stage service providers need a credible web presence that can:

- Explain what the business does
- Communicate services clearly
- Showcase prior work
- Capture inbound interest
- Provide basic navigation across pages
- Support contact and lead-generation flows

This project implements those core website patterns in React.

## Key features

- React single-page application
- Public homepage
- Service and consulting sections
- Portfolio/gallery page
- About/meet-us pages
- Contact page with EmailJS integration
- Navigation bar and footer
- Carousel-based portfolio display
- Responsive marketing-page structure

## Tech stack

- React 17
- Create React App
- React Router v5
- Bootstrap
- Styled Components
- React Elastic Carousel
- EmailJS
- SweetAlert2
- React Scroll

## Portfolio positioning

This project is useful as an early full-stack/frontend portfolio item. It shows the ability to structure a multi-page React marketing website, build reusable components, and connect a contact form to an email workflow.

For my professional portfolio, I would frame this as an early client/agency website prototype rather than a flagship technical project.

## Running locally

```bash

```

Build for production:
